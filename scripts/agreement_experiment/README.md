# Model Agreement Experiment

This folder contains the refactored runner for Experiment 1.

## Purpose

Experiment 1 compares multiple local LLM judges on the same AMP trace dataset across the original evaluator set:

- `helpfulness`
- `accuracy`
- `groundedness`
- `instruction_following`
- `reasoning_quality`

The goal is to produce one CSV per judge model so agreement, score distributions, skips, and evaluator-level differences can be analyzed later.

## Why This Folder Exists

The original runner lives at:

```text
scripts/run_gemma_runpod.py
```

That file started as a Gemma-specific Runpod script. This folder provides a cleaner experiment-specific entrypoint with:

- model-generic naming
- model-specific output CSVs
- default output directory for Experiment 1
- reusable `preprocessed_traces/`
- a dedicated Runpod shell wrapper

## Default Output

By default, outputs are written to:

```text
/workspace/model_agreement_experiment_full
```

For a model such as:

```text
google/gemma-3-1b-it
```

the result CSV is:

```text
/workspace/model_agreement_experiment_full/google_gemma-3-1b-it.csv
```

and the failure log is:

```text
/workspace/model_agreement_experiment_full/google_gemma-3-1b-it_failures.jsonl
```

If `/workspace/model_agreement_experiment_full/preprocessed_traces/` already exists, the runner reuses it instead of downloading and preprocessing the dataset again.

## Run

Set Hugging Face credentials:

```bash
export HF_TOKEN="..."
```

Run the Gemma 3 1B judge:

```bash
cd /workspace/setup

python scripts/agreement_experiment/run_model_agreement_experiment.py \
  --model google/gemma-3-1b-it \
  --batch-size 2
```

If dependencies are missing, use the wrapper:

```bash
bash scripts/agreement_experiment/run_model_agreement_experiment.sh \
  --model google/gemma-3-1b-it \
  --batch-size 2
```

Use `--batch-size 1` for the original one-prompt-at-a-time behavior. Increase the batch size only when GPU memory allows it.

## Expected Columns

The result CSV contains:

- `model`
- `trace_id`
- `evaluator`
- `level`
- `score`
- `explanation`
- `latency_ms`
- `is_skipped`
- `skip_reason`

## Copying Results Back

After a run finishes, copy the model CSV into:

```text
results /experiment 1
```

Use the same filename generated by the runner, for example:

```text
google_gemma-3-1b-it.csv
```
